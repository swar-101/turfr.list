# EditMatch UX Direction

Turfr should feel like:
- immersive football coordination UI
- not card-heavy SaaS UI
- low-tap mobile-first interaction
- operationally clear


Planning State
- editable fields
- organizer can update match
- no payments yet
- players see waiting state

Booked State
- fields become read-only
- organizer can still open EditMatch
- smart CTA changes to Cancel Turf Booking
- payments unlocked



Decisions:
- no dropdown for booking state
- no checkbox/toggle
- booking remains contextual action
- keep top info bar concise
- avoid modal/card-heavy UI



Later Ideas:
- subtle info icon indicator
- notification permission onboarding
- PWA install guidance
- stronger typography hierarchy


Current Best Next Step:
1. Group EditMatch into sections
2. Add local matchStatus state
3. Add smart booking CTA
4. Lock fields in BOOKED state
